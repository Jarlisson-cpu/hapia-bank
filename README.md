# 🦅 Harpia Bank

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

Interface de um **banco digital fictício**, o *Harpia Bank*, desenvolvida a partir de um protótipo de UI. Projeto focado em fidelidade ao design, layout e estilização com CSS.

## ✨ Telas

| Arquivo | Tela |
|---|---|
| `HAPIA/index.html` | Página inicial: "Abrir minha conta", educação financeira, investimentos, seguros |
| `HAPIA/index2.html` | Página complementar / central de atendimento |
| `HAPIA/teladelogin.html` | Tela de login |

Inclui seções de **atendimento** (WhatsApp, telefones, perguntas frequentes) e links para redes sociais.

## 🚀 Como executar

Abra `HAPIA/index.html` no navegador, ou:

```bash
# Opção 1: abra o arquivo index.html direto no navegador
# Opção 2: rode um servidor local na pasta do projeto
python -m http.server 8000
# e acesse http://localhost:8000
```

## 🧠 Conceitos praticados

Transformar protótipo em código · Flexbox · organização de múltiplas folhas de estilo · navegação entre páginas
